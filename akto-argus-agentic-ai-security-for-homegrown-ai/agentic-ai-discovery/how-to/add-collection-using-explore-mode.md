# Add collection using Explore Mode

Explore Mode lets you filter the agentic components in your inventory and save the filtered results as a group. For details on each filter type, see [Explore Mode](../concepts/explore-mode.md#filtering-agentic-components).

{% stepper %}
{% step %}
Go to **Agentic AI Discovery** > **Collections** and click **Explore mode** at the top right.
{% endstep %}

{% step %}
Select a filter type, set its value, and click **Add condition** to add more filters as needed.
{% endstep %}

{% step %}
Click **Explore Agentic components** to list the components that match your conditions.

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/explore-mode-filtered-results.png" alt="Explore Mode with a Collection Tags condition applied and the filtered Agentic components listed in a results table" width="563"><figcaption>Review the filtered components in the results table.</figcaption></figure></div>
{% endstep %}

{% step %}
Click the button at the top right to save the filtered components as a group.
{% endstep %}

{% step %}
Go back to **Agentic AI Discovery** > **Collections** and open the **Groups** tab to find the new group.
{% endstep %}
{% endstepper %}
